## 三个买之前必须知道的硬限制

**第一，超流量不停机，限速 3M。** 这条写在每一款美国机型的参数里。1.5TB 用完之后你的机器不会断网、不会被关机、也不会生成超额账单，只是带宽被压到 3Mbps。对挂机器人、跑定时脚本、维护账号在线这类场景，3Mbps 完全够用；对跑视频和大文件同步，等于流量到月中就废了。这种处理方式在低价 VPS 里不算常见，多数商家要么停机要么按 GB 收超额费，你按自己的用途判断这 3M 是保命还是判死刑。

**第二，产品页明确禁止 shadowsocks 协议。** 美国线页头写的是「严禁使用 shadowsocks 协议」，澳洲线写的是「未加中转请勿使用 shadowsocks 协议」，两句措辞不一样，含义也不一样。美国线是直接禁止，澳洲线是在没有中转的情况下不许用。官网把搭建教程单独放在一个站点上，说明它对怎么用是有明确要求的。买之前先想清楚你的用途在这条线内还是线外，别等开通了才发现要用的方式被禁。

**第三，512MB 内存是硬天花板。** 0.5GB 和 512MB 是同一件事的两种写法，这个量级装个精简系统加一个轻量服务就到顶了。宝塔面板本身的常驻内存就能吃掉大半，MySQL 再加进去基本没戏。想跑 WordPress、Typecho、数据库、Java 应用，直接跳到 AUD$39.90 那台，中间没有过渡档。

## 把参数换算成你实际能用多久

200Mbps 是峰值，不是你能一直跑的速度。按满速计算，200Mbps 等于 25MB/s，1.5TB 折合约 157 万 MB，跑满大约 17 小时就把一个月流量用完了。这个换算不是吓人，是让你明白 1.5TB 配合 200Mbps 意味着什么：它是给「大部分时间闲着、偶尔突发」的用法准备的，不是给 24 小时持续传输准备的。3Mbps 的限速兜底在这种情况下反而显得合理，至少机器还活着。

澳洲线是双向计费，2TB 双向意味着上传下载合计 2TB，单向实际只有 1TB。墨尔本那款 200Mbps 满速下，单向 1TB 大约 11 小时跑完；悉尼那款 100Mbps 慢一半，但流量池一样，能撑的时间翻倍到 23 小时左右。

真实总成本这块，官网这两条产品线展示的都是月缴价，页面上没有年付折扣、没有续费价说明、也没有退款期限。所以这里算不出第二年、第三年的支出，我也不会替你猜一个数字。下单前在结账页确认三件事：能不能年付、年付有没有折扣、续费是否维持原价。这三项直接决定它是「便宜」还是「首月便宜」。

## 线路怎么选：美国两条线，澳洲一条半

美国线的核心是 4837 和 9929 两个关键词。4837 是中国联通的骨干网，洛杉矶静态家宽那款标「4837 三网优化」，纽约 Cogent 那款标「4837 回程优化」，区别在前者去程回程都优化、后者重点是回程。9929 是中国联通另一条国际精品线路，15.90 和 16.90 两档都挂在 9929 上，官网对 16.90 那款额外加了「三网优化」的描述。美国页顶部写的是「三网回程优化，无需中转」，意思是买来直连就能用，不需要你先有一台落地机做中转。

澳洲线是另一回事。页面标题写得很直白：澳洲原生 IP，联通移动优化，**电信绕美**。也就是说电信用户访问澳洲节点，路由要绕道美国，延迟会比联通移动用户高出一截。悉尼那款补了一句「电信去程绕路、回程直连」，回程质量比去程好一些，但整体仍然不是电信友好的线路。澳洲页还注明「未加中转请勿使用 shadowsocks 协议」，等于官方承认这条线需要中转配合才好用。

按场景分：需要美国 IP 且希望直连、用途偏轻量，选 AUD$12.90 的洛杉矶静态家宽；做直播、推流、对回程稳定性有要求，选 9929 的两档；需要澳洲或亚太 IP 做本地化内容，接受电信绕路，才考虑澳洲两档。台湾和英国节点走纯国际线路，第三方测评里 Geekbench 6 单核 512 分、I/O 140 到 194MB/s 这个水平，跑一般任务够用，但延迟和路由不占优势。

## 哪些需求不该在这买

**建站、跑数据库、任何需要面板的场景。** 512MB 内存接不住，唯一选择是 AUD$39.90 那台 6GB 机型，但它同时只有一个 IP，做不了多站点隔离。

**大带宽视频、CDN、持续大流量传输。** 1.5TB 配 200Mbps 的设计是给突发用量的，不是给持续跑满的。这类需求看香港或美国不限流量的方案更合适，比如狗云的香港特惠档 1 核 1G / 15G / 30Mbps / 500GB 月流量，标价 ¥15/月；或者搬瓦工美国 1 核 1G / 20G / 1Gbps / 1TB 月流量，$49.99/年。

**要求高 SLA 的商业系统。** 官网没有公开 SLA 数值，也没有公开退款政策，商业用途缺少这两项兜底。

**需要欧洲、南美节点，或者需要 Windows。** 官网现有分类覆盖美国、澳洲、台湾、英国，欧洲其他地区和南美没有；系统方面第三方测评提到英国节点仅支持 Linux、不支持 IPv6，其他节点同样以 Linux 为主。

## 下单前确认这几件事

**币种。** 官网全线以澳元标价，结账实际扣款金额取决于支付渠道的汇率和货转费，别拿美元价格表去对。

**支付方式。** 第三方测评提到支持信用卡、PayPal 和支付宝，官网页面本身没有列出支付方式清单，结账页看到什么就是什么。

**计费周期。** 这两条产品线页面展示的是月缴价格，年付是否开放、有没有折扣，页面上没有写。想长期用的话，先问清楚再决定。

**退款。** 官网没有公开退款期限，也没有免费试用说明。第一次买建议按月付，跑满一个计费周期再决定要不要续。

**机房位置。** 洛杉矶分类页里混了一款名字带「纽约」的机型，下单时看清产品名和机房标注。

**用途合规。** 美国线禁止 shadowsocks，澳洲线要求加中转才可用。这一条比价格更值得先确认。
